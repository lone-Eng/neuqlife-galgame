# 东秦校园人生 · Galgame

一个纯前端的中文**视觉小说（Galgame）**，以东北大学秦皇岛分校的校园生活为背景。
从收到录取通知书开始，你将度过军训、开学、社团、期末竞赛、恋爱与离别的一段大学时光。

**无任何外部依赖、无构建步骤、无网络请求** —— 所有美术（立绘 / CG / 背景）、
音效与音乐（BGM / SE）全部由代码程序化生成（SVG + Web Audio）。

## 运行

直接用浏览器打开 `index.html` 即可（`file://` 协议可正常运行，未使用 ES Module）。

## 音频资源

- **`audio/` 中的 8 首 BGM**：CC0（公有领域奉献）真实录音，**可商用、无需署名**，
  覆盖标题 / 日常 / 节庆 / 恋爱 / 感伤 / 紧张 / 收束 / 撸猫。
  出处见 [audio/CREDITS.md](audio/CREDITS.md)。
- **合成音频**：另有 8 首合成 BGM 作为兜底，以及 **38 种音效**由 Web Audio 实时合成。
  游戏会按场景自动选环境音（军训哨声、雨声、鸟鸣、人群、板书声…），
  数值变化也有对应的声音（金钱、荣誉、好感…）。
- **`schoolmusic.mp3`**：校歌真实录音。合唱训练 / 彩排 / 比赛、军训拉歌等场景会自动播放。
- **换成你自己的 BGM**：把音频放进 `audio/`，然后在 [js/vn/bgm_extra.js](js/vn/bgm_extra.js)
  的 `BGM_EXTRA` 里登记一行即可：
  ```js
  var BGM_EXTRA = { bgm_campus: 'audio/campus.mp3' };
  ```
  用同名 key 登记就是"替换"合成版；文件缺失会自动退回合成曲目，删掉某行也不会有副作用。

## 架构说明

引擎分三层，单向依赖：

```
  游戏逻辑层 (js/*.js)          数据、数值、流程 —— 不知道 VN 的存在
        ↓  adapter.js 覆盖同名渲染函数
  剧本适配层 (js/vn/adapter.js)  把散文剧本解析成"节拍"，推断背景 / CG / BGM
        ↓  VN.run([...])
  演出引擎层 (js/vn/engine.js)   按节拍播放：背景、立绘、打字机、选项、特效
        ↓
  资源层 (sprites / cg / backgrounds / audio / fx)
```

**节拍（beat）** 是引擎的最小单位，例如：

```js
VN.run([
  VN.bg('sakura_path'),                                   // 切换背景
  VN.show('suxiaonuan', {emo:'smile', pos:'center'}),      // 立绘登场
  VN.say('suxiaonuan', '你今天站军姿的样子，和平时不太一样呢。'),
  VN.fx('hearts'),                                        // 特效
  VN.choice('你的选择是——', [
    {text:'温柔回应', hint:'💕 好感 +6'},
    {text:'随口敷衍', hint:'💕 好感 -2 · ⚠ 可能引发感情危机'}
  ], function(o, i){ /* 结算 */ })
]);
```

⚠️ 注意区分：`VN.bg` / `VN.say` / `VN.hide` 等是**节拍构造器**（只返回对象），
必须交给 `VN.run()` 才会执行；需要立即执行的用 `VN.hideNow()` 这类 *Now 后缀接口。

**剧本适配层**会读取原有散文化剧本，自动：
- 按引号切分旁白与台词，并从上下文推断说话人（用于显示名字牌与自动登场立绘）
- 依据标题 / 正文关键词推断场景背景，并按"夜晚"关键词切换夜间变体
- 按日期与标题匹配 CG、BGM 与特效插入点
- 为每个选项生成属性变化提示

## 存档

- 自动存档：`localStorage` 键 `dongqin_save4`
- 手动存档：6 个槽位，键 `dongqin_slot_1..6`
- CG 鉴赏解锁进度：`dongqin_vn_gallery`（跨周目保留）
- 设置：`dongqin_vn_settings`

旧版存档可直接读取（`applySaveData()` 会以默认值补齐缺失字段）。
